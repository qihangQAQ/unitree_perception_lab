# G1 喷涂任务第二版改动方案

日期：2026-10-05。状态：设计评审，尚未修改任务实现或重新训练。

本方案针对 play 中的两个问题：本体姿势异常；手臂尝试追踪目标，但身体没有随作业区域侧移。保留 reward 驱动的单一全身 PPO、29 维关节动作，不引入专家动作示范。

建议的实施顺序是：**修复动作分布失控 → 校准站姿与动作范围 → 学会正常侧移 → 学习手身协同 → 扩展到完整轨迹。** 当前 `model_17500.pt` 留作失败基线，不作为第二版默认续训起点。

### 1.1 动作失控是已确认的问题

当前链路：

```text
MLP 输出无界均值 μ
→ std = exp(log_std)，没有上界
→ 采样 Gaussian 动作
→ RSL wrapper 将动作裁剪到 [-3, 3]
→ q_target = q_default + scale × clipped_action
```

PPO 的熵奖励计算的是裁剪前 Gaussian 熵。增大 std 仍能获得熵收益，但裁剪后的动作范围不再增加。这是当前实现存在的失控机制；现有数据不能把全部因果单独归结于 entropy 系数。

checkpoint 核查结果：

- 平均 std：1047.84；最大 std：6179.77。
- 14/29 个关节的 std 大于 3，包含大量髋、踝关节。
- 对 Gaussian 任意均值，`P(|a|>3) >= erfc(3/(sqrt(2)*std))`。这 14 个关节的裁剪概率下界约 94.3%–99.96%；按全部 29 个关节平均，下界为 47.83%。这是分布解析下界，不是 rollout 中实测裁剪率。
- 额外输入合成的名义 reset 观测：五帧静态本体、关节相对位置为零、目标相对基座 `(0.28,-0.18,0.45)`、喷轴 `+x`、速度零。动作均值范围约 `[-1356,1935]`，17/29 维超过 ±3。

因此只把 play 的探索噪声关掉解决不了问题：play 本来就使用均值，而均值本身也已经越界。合成前向不等于完整仿真，但足以确认 checkpoint 在正常量级输入下存在严重输出饱和。

### 1.2 “不迈步”的奖励机制已经得到日志支持

当前身体没有速度或作业位置目标；TCP 误差超过 20 cm 后，双高斯位置 reward 几乎为零，速度 reward 又乘位置与方向 reward。目标继续沿时钟前进，身体和目标的距离越来越大，恢复追踪的回报差异越来越弱。

日志同时显示：方向、左臂奖励提高，位置跟踪没有提高。这与用户看到的“只动手、身体留在原地”一致。但现有日志没有基座位移、真实侧移速度或足底接触时序，不能从日志独立测出机器人到底走了多少。

### 1.3 姿态目标缺失与环境差异

`body_stability` 把骨盆倾斜、竖直速度和角速度放入一个指数核；没有单独约束骨盆高度、胸部倾斜、腿部横向姿态。误差大时整个核趋零，正常姿态与明显异常姿态都可能拿到接近零的值。`bad_orientation` 只检查骨盆倾斜是否超过 0.8 rad。

初始 TCP 的运动学坐标与喷轴方向经核查基本正确，不能把这次问题简单归因于 TCP 轴写反。不过初始右臂 IK 有较大的肩、腕转角，不适合直接作为“所有关节必须回归”的舒适姿态模板。

训练保存配置含有碰撞墙；当前工作区删掉了墙，`play.py` 使用当前注册配置，不自动恢复保存的 `env.yaml`。截图仍可见墙，无法仅凭当前文件确定截图进程启动时使用了哪份配置。后续评估必须记录实际生效配置，并做相同 checkpoint 的有墙/无墙对照，不能先假定靠墙支撑就是根因。

## 2. 改动 A：同时约束动作均值和探索噪声

第一版改动采用**有界均值、有界有效 std 的 Gaussian**，继续沿用 PPO 对该 Gaussian 的 log-probability 计算，减少对上游算法的改动。

1. 统一动作均值映射。例如对对称可用范围，`mu_i = m_i * tanh(z_i / m_i)`；实际使用的 `m_i` 由关节可达范围决定，不盲目给所有关节同一个上界。
2. 有效 `std_i = exp(clamp(log_std_i, log(sigma_min_i), log(sigma_max_i)))`。优化器更新后也投影参数，避免原始参数长期跑到边界外。
3. 初始诊断配置可试：动作单位下 std 初值 0.25、下限 0.05、上限 0.4；对可用动作范围约 ±3 的关节，均值范围先试 ±2。较窄的关节范围相应缩小 std。以上数值必须经过站立、侧步和右臂可达性验证。
4. 诊断短跑先设置 `entropy_coef=0`，仍由非零 Gaussian std 提供探索；正常训练从小系数如 `0.001` 起步，并随课程收敛降低。保持 `gamma=0.99` 做首轮对照，先不同时修改所有 PPO 参数。
5. 最外层裁剪保留为异常保护，记录它实际发生的比例，不再让裁剪承担常态动作整形。

必须统一三个输出路径：训练分布均值、`act_inference()`、ONNX exporter。当前 exporter 直接调用 actor MLP；如果只在 `update_distribution()` 里加边界，训练与 play/导出会再次不一致。

不要在采样结果上临时加 `tanh` 却继续使用原 Gaussian 的 action log-probability。本方案的 `tanh` 作用在**分布均值参数**上；若未来换成 squashed Gaussian，则必须另行实现变换后的 log-probability、熵和导出语义。

每个关节还要核对 `q_default + scale * a` 的范围。例如当前右腕 yaw 目标范围约 `[0.04,2.44] rad`，超过资产硬限位约 `±1.614 rad`。动作范围、scale 与软限位应一致；不能靠物理限位长期挡住不可执行的关节目标。

验收：训练和确定性推理输出均有限；均值和有效 std 满足配置边界；执行裁剪率按腿/腰/左臂/右臂分组记录，正常任务初始目标 <1%，持续 >5% 必须调查；关节目标超限率应为 0。最终门槛要结合可达性检查，不能靠缩小到无法作业来“通过”。

## 3. 改动 B：定义允许迈步的正常姿态

先做零动作 PD 保持、静态 TCP 对准和双向侧步检查，确定脚底接地的自然站姿。用带舒适度、限位和碰撞代价的离线 IK 选择右臂初始姿态；只固定初始姿态，不提供整条关节动作示范。

姿态 reward 改为分项惩罚，避免一个指数核同时掩盖全部问题：

| 项目 | 建议表达 | 初始调试范围 |
|---|---|---|
| 骨盆高度 | 高度偏离允许区间后的平方惩罚 | 在实测自然高度附近设 ±3–4 cm 容忍区；0.78–0.80 m 仅作校准起点 |
| 骨盆与胸部直立 | 分别对 roll/pitch 超出容忍区的程度惩罚 | 允许约 8–12° 的必要调整，先通过侧步验证 |
| 腿部横向姿态 | 弱约束 hip yaw/roll 偏离自然姿态、异常脚间距/交叉 | 允许侧步，不约束全腿每个关节回固定角度 |
| 腰部姿态 | 弱约束过度侧弯/扭转 | 保留作业需要的腰部调整 |
| 左臂 | 弱下垂约束与限位约束 | 降低当前独立正奖励占比，不冻结 |
| 足部 | 接触期滑动惩罚；移动时才启用轻量步态/离地辅助 | 站定画小圆时不强制抬脚 |

统一使用有物理单位的容忍区与归一化误差，按正常样本的 reward 分项统计定标。不能直接把 locomotion 所有惩罚权重复制过来，也不能新增“29 个关节全部回默认姿态”的强奖励。

严重跌倒用骨盆/胸部倾斜、过低高度和禁止的身体接触判定；为启动落地和短时噪声留合理 grace/debounce。具体阈值在站立/侧步小测试中确定。保留关节限位、能耗、动作平滑，新增扭矩饱和与接触力日志。

## 4. 改动 C：给身体可学习的侧移目标

任务仍由单个全身 PPO 输出关节动作。新增的是从已知喷涂路径计算的**身体作业目标与辅助 reward**，不是另一个执行腿部动作的控制器。

### 4.1 身体目标跟随作业区域

先以当前 TCP 舒适偏移 `r_nom_xy=(0.28,-0.18) m` 为候选，通过 FK/碰撞检查确认工作区。身体前后锚点初值 `a_x=-distance-r_nom_x`。

局部完整圆/方形应允许站定完成。若该图元横向范围是 `[y_min,y_max]`，手相对基座的舒适范围是 `[r_nom_y-R, r_nom_y+R]`，那么能够覆盖该图元的身体区间为：

```text
I = [y_max - r_nom_y - R, y_min - r_nom_y + R]
```

当 `I` 非空，把上一身体锚点投影到 `I`，在图元内保持；直线与连接段则平滑移动锚点。`R=0.18–0.20 m` 可作初始候选，但必须经全图元高度、喷轴和关节限位共同验证。若 `I` 为空，重新分段并安排身体移动，不能强制站定。

对外部路径，用同样的工作区包络原则分段；必要元数据来自已知完整路径。生成器应保留 segment 边界、类别及包围盒。锚点转换要限速、限加速度，并检查过渡期间目标仍可达；不能在图元边界跳变。

### 4.2 用身体速度 reward 提供恢复信号

```text
D(e, delta) = sign(e) * max(abs(e)-delta, 0)
v_base_cmd = limit_velocity_and_acceleration(a_dot + k * D(a - p_base, delta))
r_base = exp(-||v_base_xy - v_base_cmd_xy||^2 / sigma_base^2)
```

初值可试：`k=1.5–2.5 /s`、deadband 3–5 cm、速度上限 0.25→0.4 m/s、加速度上限 0.3–0.6 m/s²、`sigma_base=0.15 m/s`。统一在墙坐标中计算，观测转换到基座坐标；加入面墙 yaw-rate 命令。

另外记录目标 TCP 相对基座是否超出舒适工作区，必要时加弱惩罚。这里检查的是**目标位置**，不能检查实际手位置，否则手不动也能保持“在工作区内”。

不采用 `base_vy = heading * spray_speed`：圆的弧长速度不等于整体侧移速度。也不要求身体逐点追随 TCP 的瞬时切线，否则小圆会驱动来回迈步。

### 4.3 观测接口一起更新

建议现有 19 维任务输入增加：基座速度命令 3 维、身体锚点相对位置 2 维、末端任务激活标记 1 维、启动倒计时 1 维、剩余任务时间 1 维，共 **27 维**。actor 输入由 118→126，5×93 本体历史与 6 维估计器保持不变。

所有阶段使用同一接口；未激活字段有明确零值/标记。随机身体命令必须给 actor，不能只在 reward 中出现。剩余时间用于有限任务时序；准备阶段也提供未来路径几何，避免到第 1 秒才突然知道要往哪里走。

网络构造断言、训练配置、ONNX dummy input、部署 metadata、`PaintingPolicy.step()` 和测试同步更新。checkpoint 明确保存接口版本，旧 19 维 checkpoint 不做隐式兼容加载。

## 5. 改动 D：任务奖励从“站姿得分”转向跟踪和恢复

保留位置、喷轴和速度三个目标，但按阶段调整有效范围：

- 位置：保留宽窄两项。协同起步宽核先试 0.20 m，逐步收紧到 0.08 m；细核保留最终精度目标，后期提高其相对作用。
- 速度：起步容差先试 0.20 m/s，后期收紧至 0.10 m/s。早期使用 `epsilon + (1-epsilon)*r_position*r_axis` 作为门控，候选 `epsilon=0.2`；能力提升后逐步降到 0。
- 跟丢后的恢复：身体速度目标独立于 TCP 高斯核；TCP 可增加小权重、有长尾的距离项，例如 `1/(1+(e_p/0.25)^2)`，记录恢复率验证其作用。达到稳定跟踪后弱化，避免长期只追粗精度。
- 朝墙、左臂从当前主要正收益转为较弱辅助项；身体高度/倾斜等采用分项代价，不能靠它们替代主任务。

以下是归一化到约 0–1 的任务项权重起点，不是实测最优值；姿态、能耗等惩罚需按实际分项统计独立定标：

| 项目 | A 侧移 | B 水平协同 | C 曲线 | D 完整任务 |
|---|---:|---:|---:|---:|
| 身体速度跟踪 | 2.5 | 1.0 | 0.5 | 0.2–0.5 |
| TCP 位置 | 0 | 5.0 | 5.0 | 5.0 |
| 喷轴 | 弱姿态保持 | 1.0 | 1.5 | 2.0 |
| TCP 速度 | 0 | 0.5 | 1.0 | 1.0 |

身体速度辅助的后期减权以跟踪指标为条件，不机械删掉。局部图元锚点静止时，正确站定也可获得该项奖励。

## 6. 改动 E：先学侧步，再学手身协同

第 0 步先验证动作边界、关节范围、零动作站姿和训练/play 配置。通过后开始课程：

| 阶段 | 训练内容 | 初始任务范围 | 晋级关注点 |
|---|---|---|---|
| A | 站立＋双向侧移，右臂维持弱作业姿态 | 约 20% 站立，80% 侧移；左右均衡；0.10–0.25 m/s；8–12 s | 会正常迈步，身体速度达标，姿态和动作分布稳定 |
| B | 固定高度水平线，混入静态 TCP 对准 | 喷涂速度 0.10–0.15 m/s；高度约 1.25±0.03 m；距离约 0.10±0.02 m | 必须包含超出手臂舒适横向范围的路径，防止再次只用手 |
| C | 扩大高度与长度，逐步加入波形、圆和大圆角方形 | 先到 0.25 m/s，再提高曲率；分别调整一个主要难度维度 | 全身协同、转弯质量、跟丢恢复 |
| D | 原完整分布及留出路径 | 20–30 s、0.2–0.4 m/s、完整高度/距离；最后恢复右80%/左20% | 精度与稳定性，两方向分别验收 |

仅把图元概率改成 pure straight 不足以构造 B：当前连接段仍会随机改变高度。需要显式 `static`、`horizontal`、`mixed` 路径模式。静态任务不能直接设置 `speed_range=(0,0)`，当前长度和 completion 逻辑不支持零长度；应有独立保持任务与指标。

每次晋级保留约 20% 已掌握任务和少量更简单任务，均重新采集 on-policy rollout，不把历史轨迹直接塞回 PPO。所有阶段持续记录分关节 std 和饱和率。

速度爬升用 0.5–1 s 起步，并以 `s_next = min(s + v_ref*dt, L)` 推进弧长；同一控制步只更新一次。前瞻点根据未来速度曲线积分查询，不能仍用 `s + current_speed*lookahead` 处理整个加减速过程。

路径长度、速度曲线与时限必须一致。B/C 可采样长度和速度后推导时限；D 若固定采样总时限，则按速度曲线积分确定长度。线性起停 ramp 的预算为 `L=v*(Tmax-Tprepare-Tcatchup-(Tup+Tdown)/2)`。准备等待必须有上限，不能无限等待以逃避任务。

## 7. 评估、终止与课程门槛

### 7.1 新增可验证指标

每轮至少记录：基座侧向位移与命令位移、基座速度 RMSE、骨盆高度、骨盆/胸部倾斜 P95、分关节动作均值/std/裁剪率、关节限位率、扭矩饱和率、足滑及非足接触、TCP 三维误差及喷轴/速度误差。

喷涂过程指标：

```text
Q = sum(quality_pass_k * delta_s_ref_k) / planned_path_length
quality_pass = position_pass & axis_pass & velocity_pass
```

提前跌倒后剩余路段仍在分母中；准备期跌倒对应 Q=0。静态任务单独统计连续保持时间，不除以零长度。当前 `completion=progress/length` 改名 `reference_progress`，不作为完成质量。

修复零有效样本的均值日志：当前准备期跌倒可能把误差记成零；应记录 valid_count、失败原因，并避免把无样本当成完美跟踪。评估中同时报告条件误差与全任务失败率，避免幸存者偏差。

### 7.2 课程晋级使用固定评估集

每约 250 次更新评估一次，固定路径集与新随机路径分别统计；左右各至少 128 条。确定性 play 和训练采样策略都检查，防止二者差距再次扩大。窗口内统计按完整 episode 汇总，不沿用当前 reset 批次均值直接做晋级。

连续 3 次通过才晋级，候选门槛如下：

- A：时限内不跌倒 ≥98%；基座速度 RMSE <0.06–0.08 m/s；朝墙 yaw P95 <10°；正常高度和胸部姿态；双向都达标。
- B：不跌倒 ≥98%；Q≥80%，暂用位置8 cm、喷轴20°、速度误差0.15 m/s判合格；长水平线上的基座位移必须与锚点移动相符。
- C：Q≥85%，逐步收紧到位置5 cm、喷轴15°、速度误差0.12 m/s；检查小圆不强制来回迈步。
- D：可先用位置3 cm、喷轴10°、速度误差0.10 m/s、Q≥90%作为研究验收门槛；这些不是已确认的喷涂工艺标准。

难度升级后连续两次明显退化先降低任务难度；动作或数值失控则恢复上一合格 checkpoint。保存 actor/critic、估计器、两套优化器、课程状态和随机数状态。

将“终点到达”和“完整质量合格”分别记录。最终成功要求过程 Q 达标、终点位置与喷轴达标，并稳定保持约 0.2–0.5 s。若一次喷涂定义为有限任务，成功与实际任务期限结束均使用真正 termination；只有纯采样长度限制才使用 truncation/bootstrap。阶段 A 的无穷时域速度任务可以采用采样超时自举，但要明确配置，不能统一混用。

实施拆成三批，避免一次改完无法定位收益：

1. **动作与姿态基线**：动作分布边界、日志、配置一致性、站立/侧移阶段。未通过正常侧移验收，不进入复杂喷涂。
2. **水平协同**：加入身体锚点、宽容差 TCP reward 和阶段 B。比较有/无身体辅助，确认能从身体不动转为有效侧移。
3. **曲线与精度**：加入 C/D、收紧容差、质量成功判定和导出检查。最终做至少三个训练种子的固定评估。

不继续以总 reward 选最佳 checkpoint；按合格跟踪比例及姿态/稳定性约束选择。当前约 23 亿训练 transition 已经展示了失败模式，继续延长同配置训练缺乏依据。
